# Books and provenance

Agora is not an implementation of any one book. The books below are used as
**design heuristics**; where full text was not legally accessible, the notes say
so and rely only on publisher/library metadata, official previews or reviews.

| Work | Use in Agora | Evidence limit |
|---|---|---|
| Mintzberg, *The Structuring of Organizations* | contingency, differentiation/integration, coordination mechanisms | publisher metadata + secondary summaries; no pirated full text |
| Laloux, *Reinventing Organizations* | self-management/wholeness/purpose, governance caveat | official previews/summaries; not a full close reading |
| Skelton & Pais, *Team Topologies* | platform/enabling/stream-aligned roles, cognitive load, team API | published summaries/interviews; no full text |
| *The Dictator's Handbook* | selectorate/principal analogy; user as principal | publicly available summaries; analogy only, not a claim about DSH users |
| Goffman, *The Presentation of Self in Everyday Life* | front stage/back stage, presentation | metadata/secondary; no full text |
| Goffman, *Frame Analysis* | frame as a task situation and boundaries | metadata/secondary; no full text |
| Collins, *Interaction Ritual Chains* | receipts/rituals as accountability moments | metadata/secondary; no full text |
| Garfinkel, *Studies in Ethnomethodology* | accountability, indexicality, breaching | metadata/secondary; no full text |
| Durkheim, *The Division of Labour in Society* | division of labour, anomie, integration | public-domain/older edition where available; conceptual use |

## What this means

- The design commitments are explicit and testable in code/docs; the books are
  not used to prove empirical claims about software.
- No copyrighted full text is redistributed in this repository.
- If a full-text claim is needed, cite a lawful edition and page; do not infer it
  from these notes.

## Ten commitments

1. Census before opinion.
2. Frame before asset choice.
3. A route is advice, not execution.
4. Overlap needs an owner/user decision.
5. Health is evidence, not a verdict.
6. No silent destructive change.
7. The user is the principal; defaults are visible.
8. Receipts preserve reasons.
9. Fail open for hints; fail safe for mutations.
10. Open code, open limits, open provenance.
